## 📦 Overview

Configurations are organized into two groups:

* **Application-specific** — configuration shared across platforms, such as Git, Neovim, tmux, Firefox, and Visual Studio Code.
* **Platform-specific** — operating system configuration for Linux, macOS, and Windows.

Each component may contain its own README with additional setup notes and platform-specific requirements.
